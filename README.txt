# RussianItemSpawner — обновление исходников

1. Замените `ModEntry.cs` в репозитории этим файлом.
2. Удалите старый файл `manifest.json.` (с точкой в конце).
3. Добавьте этот файл с точным именем `manifest.json`.
4. Соберите проект через Stardew Mod Build Config.

В этой первой версии есть кнопка ITEM в левом верхнем углу, открытие/закрытие панели и тестовая выдача 10 камней.
Это исходники, а не готовая DLL. Сборка здесь не выполнялась; проверьте компиляцию и запуск на вашей версии SMAPI/Android.
